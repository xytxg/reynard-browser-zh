## 修复

- 合并上游下载控制、会话保活、键盘、工具栏、字体、多进程和合成器更新。
- 在新版下载状态机中保留路径/文件名校验、备份恢复、限频刷新、错误详情和可支持任务的重试。
- 避免清理正在下载或暂停的任务；失败/取消的记录不删除后来复用同名路径的文件。
- 对未知 Gecko 完成事件不执行任意路径删除；扩展生成的临时文件使用同一安全路径规则。
- 主清单丢失时不先创建空清单覆盖备份恢复；进程中断的下载在重启后标为失败。
- URLSession 不把 HTTP 错误页当成成功下载；完成时不覆盖下载期间由其他操作创建的文件。
- 修复自动合并后重复的下载状态分支及下载确认字段缺失。
- 补齐新增控制、下载错误、附加组件确认、权限提示等中文；修复动态文件夹名称被当成本地化键。

## 构建

- 当前发布基线调整为 iOS 15、arm64、Gecko 和应用扩展架构。
- 采用上游已成功运行的 LLVM/LLD、Rust、Python 3.12、Mach bootstrap 与 sccache 配置。
- 移除旧的手工 WASI 混合配置及不再使用的 Apple linker 补丁。
- 精确缓存成功编译后的 Gecko 分发文件，并解引用指向旧对象目录的符号链接。
- 主应用和两个扩展使用数字构建号；禁用 Xcode 签名并剥离嵌入运行库签名。
- 打包检查 ZIP、arm64 Mach-O、签名、扩展、构建号、最低系统和实际中文资源；验证通过后才替换输出 IPA。
- 上游定时多变体工作流移至参考目录，本仓库不自动增加每日构建。
